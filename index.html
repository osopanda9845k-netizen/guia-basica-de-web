Los 3 Pilares Web

¿Cómo funciona una página web?

Toda sitio web moderno que visitas está construido combinando tres lenguajes fundamentales que trabajan juntos para dar estructura, diseño e interactividad.

HTML Estructura

HyperText Markup Language

Es la esqueleto o estructura. Define los textos, imágenes, títulos, botones y bloques de contenido que contiene la página.

Analogía: El Esqueleto / Casa Los cimientos, muros, puertas y ventanas de una casa vacía.

CSS Apariencia

Cascading Style Sheets

Es la piel y vestimenta. Define los colores, fuentes, márgenes, tamaños, distribución y efectos visuales.

Analogía: La Pintura / Decoración El color de las paredes, los muebles, cortinas y el estilo de la casa.

JavaScript Comportamiento

Lenguaje de Programación

Es el sistema nervioso o motor. Aporta comportamiento interactivo, animaciones, lógica y respuesta a acciones del usuario.

Analogía: La Electricidad / Domótica Los interruptores de luz, el timbre y las puertas automáticas.

HTML (Lenguaje de Marcado de Hipertexto)

Define los elementos y el contenido de la página web mediante etiquetas.

¿Cómo funciona?

HTML utiliza etiquetas (tags) compuestas por un signo menor que < y mayor que > para indicar el inicio y fin de un elemento.

Etiquetas más comunes:

  • <h1> a <h6>: Títulos y encabezados.
  • <p>: Párrafos de texto.
  • <button>: Botón interactivo.
  • <a href="...">: Enlaces a otras páginas.
  • <img src="...">: Imágenes.
Código HTML de Ejemplo 
<!-- Estructura básica -->
<div class="card">
  <h2>Mi Producto</h2>
  <p>Este es un texto descriptivo.</p>
  <button>Comprar</button>
</div>
Resultado puro (Sin CSS ni JS):

Mi Producto

Este es un texto descriptivo.

CSS (Hojas de Estilo en Cascada)

Modifica el aspecto visual, colores, formas y distribución de los elementos HTML.

¿Cómo funciona?

CSS selecciona los elementos de HTML mediante Selectores y les aplica Propiedades y Valores de diseño.

Propiedades clave:

  • color / background-color: Colores de texto y fondo.
  • font-size / font-family: Tipografía y tamaño.
  • padding / margin: Espaciados internos y externos.
  • border-radius: Bordes redondeados.
Código CSS de Ejemplo 
.card {
  background-color: #2563eb;
  color: white;
  padding: 16px;
  border-radius: 8px;
}
button {
  background: #ffffff;
  color: #2563eb;
  border-radius: 4px;
}
Resultado aplicando CSS:

Mi Producto

Este es un texto descriptivo.

JavaScript (Lenguaje de Programación)

Permite reaccionar a clics, procesar datos y modificar la página dinámicamente.

¿Cómo funciona?

JavaScript escucha eventos (como clics del usuario, paso del mouse o escritura) y ejecuta funciones lógicas para alterar el HTML o el CSS sobre la marcha.

Conceptos básicos:

  • addEventListener('click'): Escucha los clics.
  • document.querySelector(): Selecciona elementos.
  • classList.toggle(): Activa/desactiva clases de CSS.
Código JavaScript de Ejemplo 
// Selecciona el botón y escucha el clic
const btn = document.querySelector('button');

btn.addEventListener('click', () => {
  alert('¡Gracias por comprar!');
});
